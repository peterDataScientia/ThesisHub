# ThesisHub

A curated catalogue of MSc dissertations and PhD theses for studying research design, scientific writing, and academic methodology.

The repository links to the original institutional records rather than redistributing copyrighted PDF files. Each entry records the author, year, degree, institution, topic and a brief note on useful methodological lessons.
